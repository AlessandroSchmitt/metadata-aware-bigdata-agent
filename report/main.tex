\begin{abstract}
This report presents a metadata-aware Text-to-Spark-SQL system for
cross-source analytics over a heterogeneous data lake.
The system combines semantic metadata retrieval, relation-aware
context expansion, SQL-safe metadata rendering, local large language
model generation, SQL validation, optional one-shot repair, and
Apache Spark execution.

The experimental evaluation investigates query correctness, metadata
retrieval quality, prompt efficiency, controlled inference latency,
catalog scalability, and Spark data-volume scalability.
\end{abstract}
